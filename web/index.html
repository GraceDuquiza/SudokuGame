Choose a box, then choose a number.

What you’ll learn today
  • Main Rule: Each row, column, and box must have all numbers once. No repeats!
  • Easy Spot: If only one number fits in a box, that’s the answer.
  • Only Choice: In some rows, columns, or boxes, only one cell can hold a number.
Tips & Controls
  • New Puzzle — Start a new board at the current level.
  • Restart — Start the current puzzle again.
  • Undo / Redo — Move backward or forward through your moves.
  • Erase — Clear the selected box. Starter numbers cannot be erased.
  • Notes — Add or remove small helper numbers.
  • Hint — Reveal one helpful move. Each puzzle includes five hints.
  • Keyboard — Use number keys to play, Space to pause, and Shift+S to stop.
  • Hearts — A wrong answer removes one heart. Five mistakes ends the game.
